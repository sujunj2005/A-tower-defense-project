# 节点系统与场景树

Godot 的核心架构基于节点（Node）和场景（Scene）的树形组织。

## 1. Node 基础

所有对象的基类。核心属性和方法：

```gdscript
# 节点名称（场景树内唯一标识）
node.name = "Player"

# 场景树检查
if node.is_inside_tree():
    print("节点已加入场景树")

# 生命周期方法
func _ready() -> void:          # 节点及其子节点就绪后调用
func _process(delta: float) -> void:  # 每帧调用
func _exit_tree() -> void:      # 退出场景树时调用
```

## 2. SceneTree

```gdscript
# 获取场景树
var tree := get_tree()

# 场景切换
get_tree().change_scene_to_file("res://scenes/main.tscn")

# 暂停/恢复
get_tree().paused = true

# 退出游戏
get_tree().quit()

# 当前场景
var root := get_tree().current_scene
```

## 3. 节点操作

```gdscript
# 添加子节点
var child := Label.new()
child.text = "Hello"
add_child(child)

# 移除/销毁
child.queue_free()    # 安全销毁（当前帧结束后）
child.free()          # 立即销毁（谨慎使用）

# 查找节点
var label := $Label                    # 直接子节点
var deep := $"%UniqueName"             # 场景唯一名称
var from_root := get_node("/root/Game/Player")  # 绝对路径
var singleton := get_node("/root/EventSystem")  # 全局单例

# 遍历子节点
for child in get_children():
    if child is Enemy:
        child.die()
```

## 4. 场景实例化

```gdscript
# 加载场景
var enemy_scene := preload("res://scenes/enemy.tscn")
# 或动态加载
var enemy_scene := load("res://scenes/enemy.tscn")

# 实例化
var enemy := enemy_scene.instantiate()
enemy.position = Vector2(100, 200)
add_child(enemy)
```

## 5. 节点类型层级

```
Node
├── CanvasItem
│   ├── Control（UI 控件）
│   │   ├── Label
│   │   ├── Button
│   │   ├── PanelContainer
│   │   ├── VBoxContainer / HBoxContainer
│   │   └── ...
│   └── Node2D（2D 节点）
│       ├── Sprite2D
│       ├── Area2D
│       ├── CharacterBody2D
│       ├── RigidBody2D
│       └── ...
└── Node3D（3D 节点）
```

## 6. 重要注意事项

- **[检查场景树状态](#)**：在信号回调中访问外部节点前，必须检查 `is_inside_tree()`
- **queue_free vs free**：首选 `queue_free()` 安全销毁，避免访问已释放内存
- **preload vs load**：`preload` 在脚本解析时加载（性能更好），`load` 在调用时加载（灵活）
- **节点路径**：`/root/` 下是 Viewport 根，所有场景和 AutoLoad 都挂载其下
