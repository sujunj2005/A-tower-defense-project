# 物理与运动

Godot 4.x 提供多种物理体节点来处理 2D/3D 物理和运动。

## 1. CharacterBody2D

用于角色控制（玩家、NPC），通过 `move_and_slide()` 处理运动：

```gdscript
extends CharacterBody2D

@export var speed: float = 200.0

func _physics_process(delta: float) -> void:
    var direction := Input.get_vector("ui_left", "ui_right", "ui_up", "ui_down")
    velocity = direction * speed
    move_and_slide()
```

## 2. Area2D

用于检测区域（触发器、拾取范围、攻击范围）：

```gdscript
extends Area2D

func _ready() -> void:
    area_entered.connect(_on_area_entered)
    body_entered.connect(_on_body_entered)

func _on_body_entered(body: Node2D) -> void:
    if body.is_in_group("player"):
        trigger_event()
```

## 3. RigidBody2D

用于物理模拟的刚体：

```gdscript
extends RigidBody2D

func _ready() -> void:
    gravity_scale = 1.0
    mass = 2.0
```

## 4. 碰撞层与遮罩

```gdscript
# collision_layer：该物体属于哪个层
# collision_mask：该物体检测哪些层
collision_layer = 1    # 第 0 位 -> 属于层 1
collision_mask = 1     # 检测层 1

# 用位运算设置多层
collision_mask = (1 << 0) | (1 << 1)  # 检测层 1 和 2
```

## 5. 射线检测

```gdscript
var space_state := get_world_2d().direct_space_state
var query := PhysicsRayQueryParameters2D.create(from, to)
query.collision_mask = collision_mask
var result := space_state.intersect_ray(query)
if not result.is_empty():
    var collider := result["collider"]
    var point := result["position"]
```

## 6. 物理层

```gdscript
# 常用物理层命名约定
const LAYER_WORLD: int = 1 << 0    # 0: 世界/地面
const LAYER_PLAYER: int = 1 << 1   # 1: 玩家
const LAYER_ENEMY: int = 1 << 2    # 2: 敌人

```

## 7. _physics_process vs _process

| 方法 | 调用频率 | 用途 |
|------|---------|------|
| `_process(delta)` | 每帧（可变） | 视觉更新、输入轮询 |
| `_physics_process(delta)` | 固定频率（默认60Hz） | 物理运动、碰撞处理 |

```gdscript
func _process(delta: float) -> void:
    # 视觉更新、动画
    update_animation()

func _physics_process(delta: float) -> void:
    # 物理运动
    velocity = calculate_velocity()
    move_and_slide()
```
