## 1. 2D 工作区

### 1.1 切换到 2D 工作区

- 选择场景树中的 2D 节点
- 使用编辑器顶部的工作区选择器

### 1.2 拖放节点

从文件系统拖放兼容节点到视口：

- 默认：添加为选中节点的兄弟节点
- `Shift`：添加为选中节点的子节点
- `Alt`：添加为根节点的子节点
- `Alt + Shift`：可选择节点类型

## 2. 坐标系

### 2.1 2D 坐标系

- 只有 X 和 Y 两个轴
- 视角固定
- 向右和向下为正方向
- 原点在 (0, 0)

### 2.2 视口显示

- 红线：X 轴
- 绿线：Y 轴
- 两条线交点：原点

## 3. 主工具栏

### 3.1 选择模式 (Q)

- 左键点击选择节点
- 左键拖动矩形选择多个节点
- `Shift` 添加/移除选择
- 拖动移动节点
- `Ctrl` 临时切换到旋转模式
- 红色圆圈缩放

### 3.2 移动模式 (W)

显示移动控制器，可拖动移动节点。

### 3.3 旋转模式 (E)

显示旋转控制器，可拖动旋转节点。

### 3.4 缩放模式 (S)

显示缩放控制器，可拖动缩放节点。

### 3.5 旋转轴心

设置节点旋转的中心点：

- 默认在 (0, 0)
- `Shift + 点击`：在选中节点中心创建轴心

### 3.6 平移模式 (G)

导航视口而不意外选择节点。

### 3.7 标尺模式 (R)

- 点击显示全局坐标
- 拖动测量距离
- 对角拖动显示三角形和角度

### 3.8 吸附工具

| 工具 | 说明 |
|------|------|
| 智能吸附 | 吸附到节点边缘、中心等 |
| 网格吸附 | 吸附到网格 |
| 旋转吸附 | 按角度步进吸附 |
| 缩放吸附 | 按缩放步进吸附 |

### 3.9 锁定和分组

- `Ctrl + L`：锁定选中节点
- `Ctrl + G`：分组选中节点

## 4. 视口操作

### 4.1 导航

- 中键拖动：平移视图
- 滚轮：缩放
- `F`：居中选中节点
- `Shift + F`：框选选中节点

### 4.2 标尺和参考线

- 视口左上角黑色条是标尺
- 从标尺拖动创建参考线
- 参考线可用于对齐
- `Y` 切换参考线可见性

### 4.3 View 菜单

| 选项 | 说明 |
|------|------|
| Grid | 显示网格 |
| Show Helpers | 显示变换辅助线 |
| Show Rulers | 显示标尺 |
| Show Guides | 显示参考线 |
| Show Origin | 显示原点线 |
| Show Viewport | 显示视口矩形 |
| Clear Guides | 清除所有参考线 |

## 5. Node2D 和 Control

### 5.1 继承关系

```
CanvasItem (2D 基类)
├── Node2D (2D 游戏对象基类)
└── Control (GUI 基类)
```

### 5.2 Node2D

用于 2D 游戏对象：
- `Sprite2D`
- `AnimatedSprite2D`
- `CharacterBody2D`
- `Area2D`

### 5.3 Control

用于 UI 元素：
- `Button`
- `Label`
- `Container`
