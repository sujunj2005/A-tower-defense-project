## 1. Profiler 概述

### 1.1 什么是 Profiler

性能分析器是测量程序各部分运行时间的工具。它帮助找到性能瓶颈。

### 1.2 Godot 的 Profiler

Godot IDE 提供内置的性能分析器，可以：
- 测量函数调用次数和时间
- 分析内存分配
- 查看 GPU 时间
- 监控帧率

## 2. 内置 Profiler

### 2.1 打开方式

1. 运行游戏
2. 点击 Debugger → Profiler
3. 选择要监控的数据类型

### 2.2 数据类型

| 类型 | 说明 |
|------|------|
| Time | 函数执行时间 |
| Memory | 内存使用情况 |
| Physics | 物理引擎性能 |
| Audio | 音频系统性能 |

### 2.3 录制步骤

1. 点击 "开始录制"
2. 操作游戏一段时间
3. 点击 "停止录制"
4. 查看结果图表

> **踩坑点**：录制期间帧率会显著下降，这是正常现象。

## 3. 分析结果解读

### 3.1 找出瓶颈

- 如果某函数占用时间明显多 → 主要瓶颈
- 如果大部分时间在驱动/GPU → 图形瓶颈
- 如果有周期性峰值 → 可能是 GC 或定时任务

### 3.2 关键指标

| 指标 | 含义 |
|------|------|
| Frame Time | 单帧耗时（ms） |
| FPS | 帧率 |
| Object Count | 场景中对象数量 |
| Node Count | 节点数量 |
| Resource Count | 加载的资源数 |

## 4. 常见性能问题

### 4.1 CPU 问题

| 问题 | 解决方案 |
|------|----------|
| `_process()` 中大量计算 | 移至 `_physics_process()` 或减少频率 |
| 频繁创建/销毁对象 | 使用对象池 |
| 大量 `get_node()` 调用 | 缓存引用 |
| 复杂算法 | 优化或缓存结果 |

### 4.2 GPU 问题

| 问题 | 解决方案 |
|------|----------|
| 绘制调用过多 | 合并精灵、使用 Sprite Sheet |
| 高分辨率纹理 | 降低分辨率、压缩格式 |
| 复杂着色器 | 简化或 LOD |
| 全屏后处理 | 降低分辨率或禁用 |

### 4.3 内存问题

| 问题 | 解决方案 |
|------|----------|
| 内存持续增长 | 检查对象是否正确释放 |
| 大量纹理未释放 | 使用 `ResourceLoader.unload_ref()` |
| 泄漏 | 使用 Memory Profiler 检查 |
