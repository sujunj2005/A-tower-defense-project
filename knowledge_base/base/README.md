# Godot 官方文档（Base 目录）

## 📚 说明

本目录存放 Godot 官方文档的离线版本，作为知识库的基础参考资料。

## 📦 当前收录

### Godot 4.x Master 分支文档
- **位置**: `./godot-official-docs/`
- **来源**: https://github.com/godotengine/godot-docs (master 分支)
- **大小**: ~232 MB
- **文件数**: 3,621 个
- **内容**:
  - `getting_started/` - 入门教程
  - `tutorials/` - 各类技术教程
  - `classes/` - 完整的 API 类参考文档
  - `about/` - 项目介绍
  - `community/` - 社区资源
  - `engine_details/` - 引擎细节

## 🎯 使用建议

1. **快速查询 API** → 查看 `classes/` 目录
2. **学习特定功能** → 查看 `tutorials/` 对应章节
3. **入门学习** → 从 `getting_started/` 开始
4. **深入理解** → 参考 `engine_details/`
