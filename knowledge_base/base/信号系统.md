# 信号系统

Godot 4.x 信号（Signal）是节点间解耦通信的核心机制。

## 1. 声明信号

```gdscript
# 无参数信号
signal died

# 带参数的信号
signal health_changed(new_health: int)
signal option_selected(option_index: int)

# 可在任何类中声明
extends Node
signal game_started(level: int)
```

## 2. 发射信号

```gdscript
# emit（Godot 4 新语法）
health_changed.emit(health)
died.emit()

# 旧语法（仍兼容）
emit_signal("health_changed", health)
```

## 3. 连接信号

```gdscript
# 代码连接
func _ready() -> void:
    player.health_changed.connect(_on_health_changed)
    button.pressed.connect(_on_button_pressed)

# 回调函数
func _on_health_changed(new_health: int) -> void:
    health_bar.value = new_health

# 断开连接
player.health_changed.disconnect(_on_health_changed)

# 一次性连接
timer.timeout.connect(_on_timeout, CONNECT_ONE_SHOT)
```

## 4. 编辑器连接

在编辑器中通过 Node 面板的 Signals 选项卡可视化连接，自动生成 `_on_xxx()` 回调函数。

## 5. 自定义信号实践

```gdscript
# Event UI 信号示例（来自项目 event_ui.gd）
extends Control

signal option_selected(option_index: int)
signal event_completed

func _on_option_pressed(index: int) -> void:
    option_selected.emit(index)

# 外部连接
event_ui.option_selected.connect(_on_option_selected)
```

## 6. AutoLoad 单例的信号

```gdscript
# 通过 AutoLoad 的全局单例通信
func _ready() -> void:
    EventSystem.event_triggered.connect(_on_event_triggered)

func _on_event_triggered(event_data: EventData) -> void:
    show_event(event_data)
```

## 7. 重要注意事项

- **信号回调中的安全检查**：如果回调中可能访问 `/root/XXX` 全局节点，必须先调用 `is_inside_tree()`
- **先 disconnect 再 connect**：避免重复连接导致多次调用
- **queue_free 后不操作**：`queue_free()` 后立即 `return`，不访问任何成员变量
- **信号参数类型标注**：声明时标注参数类型，编译器可做类型检查
