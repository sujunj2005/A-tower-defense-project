## 现象

游戏进行到中后期，玩家的防御塔数量严重不足，无法应对难度递增的敌人波次。排查发现：

- 44 个事件选项完全缺少防御塔（tower）类型的奖励
- 这些选项仅提供 gold、attribute、trait 等奖励，漏掉了 tower_gains
- 导致玩家通过事件获取防御塔的渠道严重不足

## 根因

在事件数据配置（`data/events.json`）中，大量选项的 `tower_gains` 字段为空数组 `[]` 或未定义。事件设计时偏重了非 tower 类奖励，忽略了 tower 奖励是游戏核心成长维度之一。

具体原因：
1. 批量生成事件时未将 tower 奖励纳入配置模板
2. 缺少事件配置完整性审查机制
3. 数值策划未明确青年期/中年期 tower 奖励的分配比例

## 修复

为 44 个缺失防御塔的选项批量补充 tower 奖励：

```json
# 修复前
{
    "option_id": "EVT_YOUNG_012_O1",
    "tower_gains": []
}

# 修复后
{
    "option_id": "EVT_YOUNG_012_O1",
    "tower_gains": ["tower_arrow_lv1", "tower_arrow_lv1", "tower_magic_lv1"]
}
```

数值平衡策略：
- **青年期事件（age < 24）**：给大量 tower_gains，体现成长阶段优势，tower_gains 配置 3-6 个
- **中年期事件（age >= 24）**：给部分 tower_gains，体现积累和权衡，tower_gains 配置 1-3 个
- **小数值选项**：tower_gains 1-3 个
- **大数值选项**：tower_gains 3-6 个

## 预防

1. **事件配置检查清单增加「tower 奖励」必检项**：
   - 每个选项是否包含合理的 `tower_gains` 数量？
   - 青年期选项 tower 奖励是否充足？
   - tower 奖励的等级分布是否合理？
2. 建立事件配置自动验证脚本（`tools/validate_events_v2.py` 中增加 tower_gains 检查）
3. 设计阶段先制定 tower 奖励在各年龄段的比例规划表
