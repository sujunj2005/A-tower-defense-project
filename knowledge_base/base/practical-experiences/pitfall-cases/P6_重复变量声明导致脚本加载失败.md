## 现象

启动游戏或运行编辑器时，`birthday_tab.gd` 脚本加载失败，Godot 编辑器报错：

```
Parse Error: The variable "_moon_zodiac_label" already exists in this class.
```

脚本完全无法加载，导致对应 UI 功能缺失。

## 根因

同一 GDScript 文件中，变量 `_moon_zodiac_label` 被声明了两次：

```gdscript
# 第一次声明（第 15 行附近）
@onready var _moon_zodiac_label: Label = $MoonZodiacLabel

# ... 很多行之后 ...

# 第二次声明（第 78 行附近）—— 导致 Parse Error
var _moon_zodiac_label: Label
```

GDScript 编译器在解析阶段检测到重复标识符，拒绝加载该脚本。这种情况通常发生在：
1. 复制粘贴代码时不小心复制了变量声明
2. 重构过程中移动了 `@onready var` 但忘记删除原位置的 `var` 声明
3. 合并代码冲突时保留了双方的声明

## 修复

删除多余的变量声明行，保留第一次的 `@onready var` 声明：

```gdscript
# 仅保留此声明
@onready var _moon_zodiac_label: Label = $MoonZodiacLabel

# 删除以下重复声明
# var _moon_zodiac_label: Label  ← 已删除
```

## 预防

1. **编码完成后立即运行编辑器验证** — 检查 Output 面板是否有 Parse Error
2. 在 `extends`/`signal`/`var`/`enum`/`const` 等声明区域附近避免直接复制粘贴
3. 使用版本管理查看 diff，审查新增的声明行是否与已有声明重复
4. 使用 IDE 的「查找引用」功能，在添加新变量前确认名称未被占用
5. 建议使用命名前缀约定（如 `_` 前缀为私有变量），减少命名冲突概率
