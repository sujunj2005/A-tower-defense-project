# 运行时安全实践

防止场景树访问崩溃和内存访问错误的最佳实践。

## 🔴 强制规范

### 1. 外部节点访问保护

在信号回调、异步操作或 timer 回调中访问 `/root/XXX` 全局节点前，必须检查 `is_inside_tree()`：

```gdscript
# 正确写法
func _on_option_pressed(index: int) -> void:
    # 先释放自身
    queue_free()

    # 访问外部节点前检查
    if not is_inside_tree():
        return
    var event_system := get_node("/root/EventSystem") as EventSystem
    if event_system:
        event_system.select_option(index)

# 错误写法（可能崩溃）
func _on_option_pressed(index: int) -> void:
    queue_free()
    # 直接访问——此时可能已不在场景树中
    var event_system := get_node("/root/EventSystem")
    event_system.select_option(index)
```

### 2. queue_free 后不操作

调用 `queue_free()` 后必须立即 `return`，不在之后访问任何成员变量或调用方法：

```gdscript
# 正确写法
func _on_close_pressed() -> void:
    queue_free()
    return  # 立即返回

# 错误写法
func _on_close_pressed() -> void:
    queue_free()
    _cleanup_resources()  # 错误：在 queue_free 后操作
    emit_signal("closed") # 错误：可能触发异常
```

### 3. 重复变量声明检查

```gdscript
# 错误：变量重复声明导致脚本加载失败
@onready var _moon_zodiac_label: Label = $MoonZodiacLabel
# ... 很多行之后 ...
var _moon_zodiac_label: Label  # Parse Error: 重复声明

# 正确：每个变量只声明一次
@onready var _moon_zodiac_label: Label = $MoonZodiacLabel
```

## 🟡 建议规范

### 4. 编码安全流程

```
编写代码 → 运行编辑器验证 → 检查 Output 面板 → 确认无 Parse Error → 运行场景测试
```

- 完成后立即运行编辑器，检查 Output 面板是否有 Parse Error
- 在 extends/signal/var/enum 区域附近避免复制粘贴，减少重复声明风险
- 使用版本管理工具保存修改前版本

### 5. 节点查找安全模式

```gdscript
# 使用类型安全的查找
var event_system := get_node_or_null("/root/EventSystem") as EventSystem
if not event_system:
    push_warning("EventSystem not found")
    return

# 或用唯一名称查找
var label := $"%TitleLabel"
if not label:
    push_error("TitleLabel not found in scene")
    return
```
