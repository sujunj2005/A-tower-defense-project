# 地图系统踩坑记录

> **最近核对**：2026-11-27，TestMCP 当前代码与 Godot 4.6.2

## 1. MapConfig Resource 格式不适合 xlsx 表格化

项目用 `resources/maps/*.tres` 保存 `MapConfig`，包含路点、塔位、尺寸、时代和难度参数。Excel 配置工具负责 JSON 配置。地图资源通过 Godot 的资源编辑器维护。[地图配置类](../../scripts/logic/tower_defense/map_config.gd) · [示例地图](../../resources/maps/map_school.tres)

## 2. 目录扫描注册表实现

`_static_init()` 使用 `DirAccess` 扫描 `res://resources/maps/` 里的 `.tres`，从文件名推导 ID，再确认资源是 `MapConfig`。扫描结果为空时，才启用 `map_01` 和 `map_test` 的内置表。Godot 4.6.2 源码工程实测可注册 7 张地图。

`get_next()` 返回空字符串时会自动结束遍历，提前跳出循环时可显式调用 `list_dir_end()`。打包后原始目录项可能与源码目录不同，发行验证应在实际导出包中检查地图表。[注册表实现](../../scripts/logic/tower_defense/map_config.gd) · [Godot DirAccess 类参考](../base/godot-official-docs/classes/class_diraccess.rst)

## 3. 地图权重累加时机

选项提交时将 `map_weights` 加入本局累计值。战斗选图按以下顺序进行。

1. 使用 `battle_trigger.force_map_id` 指定的地图。选项根层的同名字段当前不参与选图。
2. 致命战斗使用 `map_hospital`。
3. 普通战斗从已注册、无时代限制或与当前时代匹配的地图中取最高累计权重。同分时保留当前遍历中最先达到最高值的一项。有累积记录却没有合格地图时回落到 `map_01`。
4. 普通战斗没有累计值时使用 `map_01`。

累计值仅在第 3 条被消费并清空。强制地图或致命战斗会保留累计值。这个字段没有写入 `GameSessionData.to_dict()`，因此读档不能带回此前尚未消费的地图权重。[选择与选图](../../scripts/logic/life_simulation/event_system.gd) · [局内序列化](../../scripts/bean/session_data.gd)

## 4. 敌人属性缩放时机

出怪时先执行 `enemy.initialize()`，再按实例倍率调整当前血量与血条上限、当前值。敌人漏过防线时，基地伤害以配置中的 `damage` 乘实例的伤害倍率，再处理特质减免。共享的 `EnemyConfig` 保留基础配置。[生成与基地扣血](../../scripts/managers/map_manager.gd)

## 5. waypoints 路径计算限制

路点至少有两个时，`compute_path_from_waypoints()` 展开成道路使用的格子。否则沿用资源中的 `path_points`。当前算法在每一步同时推进尚有方向的轴，未实现任意斜线插值。测试 `(0,0) → (3,1)` 时实际生成 `(0,0)、(1,1)、(2,2)、(3,1)`。地图资源应使用水平和垂直路段。

敌人移动会优先将原始 `waypoints` 转为格子中心，绘制道路则使用展开后的格子。检查新路径时应同时观察敌人路线和道路铺设。[路点展开](../../scripts/logic/tower_defense/map_config.gd) · [道路与移动路径](../../scripts/managers/map_manager.gd)

## 6. 全局难度配置读取

用 `session.global_difficulty` 从 `game_config.json` 的 `difficulty_presets` 取全局生命与伤害倍率，两项再分别乘地图的 `enemy_attribute_multiplier`。缺省倍率是 1.0。[难度读取](../../scripts/managers/map_manager.gd) · [全局配置](../../data/game_config.json)

## 8. TileMapLayer 与坐标

战斗场景的 `GroundLayer` 是单层 `TileMapLayer`，地形通过 `set_cells_terrain_connect()` 成批写入。节点缩放用于将原 48 像素瓦片尺寸对应到 `MapConfig.tile_size`。调用 `local_to_map()` 前先把画布全局坐标用 `to_local()` 转成层内坐标。需要全局格心时用 `to_global(map_to_local(cell))`。Godot 4.6.2 已用带缩放和位移的图层验证往返。[战斗场景](../../scenes/map.tscn) · [TileMapLayer API](../wiki/concepts/tilemaps-concept.md)
