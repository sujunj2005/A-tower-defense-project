**enemy.gd 修改：**
1. 新增变量 `var difficulty_multiplier: float = 1.0`（放在现有变量区域）
2. 新增变量 `var damage_multiplier: float = 1.0`
3. 在 initialize() 方法末尾，如果 difficulty_multiplier != 1.0，缩放血量：
   ```gdscript
   if difficulty_multiplier != 1.0:
       current_health = int(float(current_health) * difficulty_multiplier)
       max_health = current_health
   ```
4. 找到敌人造成伤害的地方（_on_reached_base 或类似方法），将 damage 乘以 damage_multiplier

**map_manager.gd 修改：**
1. 新增方法 `_get_difficulty_multipliers() -> Dictionary`：
   - 从 game_config.json 读取 difficulty_presets
   - 根据 session.global_difficulty 获取全局倍率
   - 从 map_config 获取地图倍率（enemy_attribute_multiplier）
   - 返回 `{"health": global_health * map_multiplier, "damage": global_damage * map_multiplier}`

2. 修改 _on_enemy_spawn_requested()（约第 207 行），在 enemy.initialize() 之后添加：
   ```gdscript
   var multipliers: Dictionary = _get_difficulty_multipliers()
   enemy.difficulty_multiplier = multipliers.get("health", 1.0)
   enemy.damage_multiplier = multipliers.get("damage", 1.0)
   if enemy.difficulty_multiplier != 1.0:
       enemy.current_health = int(float(enemy.current_health) * enemy.difficulty_multiplier)
       enemy.max_health = enemy.current_health
   ```
   注意：血量缩放在这里统一处理，enemy.gd 的 initialize() 中不需要重复处理。
  </action>
  <verify>敌人血量根据难度倍率正确缩放</verify>
